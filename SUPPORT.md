# Getting help

- **How to use nixkeeper, what you'd like it to do:**
  [nixkeeper's Discussions](https://github.com/nixkeeper/nixkeeper/discussions).
- **What the page shows:**
  [Reading the page](https://github.com/nixkeeper/nixkeeper/blob/main/docs/reading-the-page.md).
- **Something wrong:** an issue in the repository it's about (a digest's
  data in that digest, the page in nixkeeper).
- **Is something late or down?** [status.nixkeeper.com](https://status.nixkeeper.com/)
  says, and its [open issues](https://github.com/nixkeeper/status/issues)
  are what's being looked at.
- **A security problem:** privately, as the [security policy](SECURITY.md)
  says.
